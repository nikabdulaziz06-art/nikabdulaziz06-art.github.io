# 🥦 Lari Sihat: Misi Tenaga

Permainan pendidikan **SDG 3: Kesihatan Baik & Kesejahteraan**.
Topik ESD: **Pemakanan sihat dan gaya hidup aktif**.

**Main sekarang:**
- Versi 2D: https://nikabdulaziz06-art.github.io
- Versi 3D (mod melintang): https://nikabdulaziz06-art.github.io/3d.html

Versi 3D: 3 lorong (leret kiri/kanan atau ◀ ▶), leret ke atas / sentuh untuk lompat, 2 kali untuk lompat tinggi. Paling seronok dalam mod melintang di telefon. Three.js r128 (MIT) disimpan dalam `lib/`.

## Cara bermain
- Pilih avatar comel: 🐰 Arnab, 🐱 Kucing atau 🐼 Panda.
- Untuk bergerak, avatar perlukan **tenaga** ⚡, dan tenaga **hanya** datang daripada menjawab soalan (jawapan betul = +40). Permainan bermula dengan 0 tenaga.
- Tenaga berkurang semasa berlari dan melompat. Bila habis, avatar berhenti dan soalan baru muncul.
- Lompat melepasi dinding tanah 🧱 dan tunggul. Untuk pokok tinggi 🌳, tekan LOMPAT **2 kali** (lompat berganda). Langgar = hilang nyawa.
- Kutip makanan sihat 🍎🥦 untuk skor tambahan.
- Kawalan: SPACE / ↑ / sentuh skrin / butang LOMPAT (2 kali untuk lompat tinggi) · P = rehat · 1–4 = pilih jawapan.

## Zon dan topik soalan
1. 🧺 Isih Makanan (kumpulan makanan & Piramid Makanan)
2. 🍽️ Tabiat Makan Sihat
3. 🥗 Simulator Makanan Sihat (Pinggan Sihat Malaysia: suku-suku-separuh)
4. 🧘 Minda Tenang (cara elak overthinking)
5. 📅 Rutin Harian Sihat (tabiat, tidur, aktiviti fizikal)

## Muzik
Lagu latar ceria ialah gubahan asli yang disintesis terus dalam pelayar (`lib/music.js`, Web Audio API), jadi tiada fail audio atau isu hak cipta. Kekunci lagu bertukar setiap zon, muzik jadi perlahan semasa kuiz, dan ada fanfara bila menang. Butang 🎵 untuk hidup/matikan muzik, 🔊 untuk kesan bunyi.
